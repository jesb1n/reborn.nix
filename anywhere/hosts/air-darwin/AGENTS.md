# air-darwin — Agent Instructions

Host rules for `air-darwin` (Jesbin's MacBook Air, Apple M4). Read before
editing `darwin-configuration.nix` or `home.nix`. The stack is the same as
`pro-darwin`; `hosts/pro-darwin/AGENTS.md` applies wherever this file is
silent (Determinate quirks, Homebrew danger, activation-script rules,
`home.homeDirectory` needing `lib.mkForce`).

The owner wants these files at the bare minimum: no comments, no setting
whose value equals the module default, nothing declared "for later".
Explain decisions here, not in the Nix files.

## Fresh-install bootstrap

The config was written for a reimaged machine. Before the first switch:

1. Restore `~/.ssh/id_ed25519` (+ `.pub`), `~/.config/sops/age/keys.txt` and
   `~/.kube/s145.yaml` from backup. Activation copies the SSH key to
   `/etc/nix/fleet-builder-key` and fails if it is missing.
2. Install Determinate Nix: `curl -fsSL https://install.determinate.systems/nix | sh -s -- install`.
3. Clone the repo, then from `anywhere/`:

```bash
nix eval --raw .#darwinConfigurations.air-darwin.system.drvPath
sudo nix run github:LnL7/nix-darwin#darwin-rebuild -- switch --flake .#air-darwin
```

If nix-darwin reports `/etc/zshrc` or `/etc/bashrc` "in the way", move them
aside with a `.before-nix-darwin` suffix and rerun. nix-homebrew installs
Homebrew itself when `/opt/homebrew` is absent. Log out once afterwards for
Touch ID sudo and the firewall change to take effect.

## What is deliberately different from pro-darwin

- **Builders** are declared with `determinateNix.buildMachines` (named fields)
  rather than a hand-written `/etc/nix/machines`; the rendered file is the
  same two lines. `tests/fleet-invariants.nix` mirrors both Macs.
- **Prompt:** Powerlevel10k + oh-my-zsh `git` plugin, font MesloLGS Nerd Font.
  `~/.p10k.zsh` is generated by `home.nix`: it sources the package's
  `p10k-lean.zsh` template and then applies the owner's wizard choices as
  overrides. Instant prompt is off, so the `.zshrc` needs no early block.
  Change the prompt by editing those lines, not by running `p10k configure`
  (its output file is read-only).
- **Terminal:** Warp (cask). No iTerm2, no dynamic profile. Pick "MesloLGS Nerd
  Font" in Warp's settings for the p10k glyphs.
- **No SSH agent, no 1Password, no gcloud/aws tooling, no MCP servers, no
  sops-nix, no nix-index, no global pre-commit template.** Run
  `pre-commit install` once per repo instead.
- **Containers:** OrbStack cask, which ships its own `docker` and `docker compose`
  CLIs. `homebrew.brews` is absent on purpose.
- **All CLI tools come from Nix** (`home.packages`). Do not add formulae for
  tools that nixpkgs provides.

## Dropped on purpose (do not re-add without asking)

Casks: `cloudflare-warp`, `cursor`, `hermes-desktop`, `loom`, `transmission`,
`utm`, `vlc`, `telegram`, `google-chrome`, `handy`, `antigravity`.
Packages: `ripgrep`, `fd`, `yq-go`, `tmux`, `nmap`, `sshpass`, `immich-cli`,
`iterm2`. These were on the previous install and the owner chose to leave them out.

Settings removed because they equal the default: `homebrew.onActivation.cleanup`
(`"none"` is the default — still never set it to anything else),
`onActivation.autoUpdate`, `determinateNix.enable`, `nix-homebrew.autoMigrate`,
Dock `minimize-to-application` and the Quick Note hot corner, trackpad force
click, zsh `ignoreDups`/`share`, fzf and direnv zsh integration.

## Do NOT

- Set `nix.*` options — Determinate owns the daemon; use `determinateNix.*`.
- Set `homebrew.onActivation.cleanup` to anything but `"none"` (the default).
- Run `brew tap` or set `mutableTaps = true`; add a flake input instead.
- Use `system.activationScripts.<customName>`; only `preActivation`,
  `extraActivation` and `postActivation` run.
- Copy pro-darwin's `home.stateVersion = "24.05"`; this host started at `26.11`.
- Add comments or default-valued settings to the Nix files; document here.
- Commit `anywhere/result`.
